# setup.sh installs with --require-hashes, thus each line below needs its hash
# or the installation stops. Each hash is of the file on PyPI, and both
# platforms use CPython 3.13: a different version of Python asks for a wheel
# that is not in this file.
#
# Ten packages ship a wheel for each platform, and each one has TWO lines with
# a marker of the platform, and not one line with two hashes. pip takes a file
# that matches ANY hash of the line, and it decides the platform from the name
# that the index gives. Thus one line with both hashes lets an index give the
# bytes of the win_amd64 wheel under the name of the aarch64 wheel, and the
# appliance takes a library that cannot operate on it. The marker binds the one
# hash to the one platform.
#
# Section 13 of deploy/README.md gives the way to make this file again, and the
# reason that the index matters.
