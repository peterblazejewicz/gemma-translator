# --- names of the enclosure, added 2026-08-10 ---
#
# switch      - a switch (n) is a component that a person operates. The
#               dictionary refuses "to switch" (v) and gives SET (v). This is
#               the same class of false result as file, log, and request above.
#               The appliance has three: two push-to-talk and one for the
#               electrical supply.
# cover glass - the glass at the front of the display module. It is the name
#               that the Raspberry Pi document uses, and the perimeter of the
#               module is bare cover glass, which is what the rebate carries.
# rebate      - a step at the top of a wall that a part sits in. It is the
#               name of the feature in woodwork and in a machine shop.
# chamfer     - a face at 45 degrees at an edge. It is the name of the feature
#               in a machine shop.
switch
cover glass
rebate
chamfer

# --- names of the GPIO configuration ---
#
# momentary   - a momentary switch. It is the name of the type of the
#               component. The dictionary gives MOMENTARILY (adv), which is a
#               different part of speech.
# interrupt   - an interrupt (n) of the processor, which /proc/interrupts
#               counts. The dictionary refuses "to interrupt" (v). This is the
#               same class of false result as file, log, and request above.
# register    - a register (n) of a device on the I2C bus. The dictionary
#               refuses "to register" (v).
# state       - a state (n): the "state of charge" of a cell, and a state of
#               pinctrl. The dictionary refuses "to state" (v).
# fuel gauge  - the class of the device that measures the charge of a cell. It
#               is the name that Maxim and the Linux kernel both use.
# significant - part of "most significant byte", the name of the sequence of
#               the bytes of a value.
# repeated    - part of "repeated start", the name of the operation of I2C
#               that reads a register.
#
# guard       - the low battery guard, which is the name of the component in
#               deploy/gemma-battery-guard.sh, in the name of its unit, and in
#               its Description. The dictionary refuses "to guard" (v). This is
#               the same class of false result as file, log, and request above.
guard
